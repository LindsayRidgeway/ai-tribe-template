# Things the human has dropped into the workshop

Appended, never rewritten. A drop is a twig or a bit of food: it changes what a member might do next,
and it is not an instruction. If a drop contradicts an open item, the drop wins and the member should
say so.

Two rows below are the workshop's own history: this world arrived with them. **Nobody in your circle dropped
them, and the first row does not say "you" for a reason** — a file that signs a person's name to something they
never did is a small lie that a member will then build on. Delete them, or leave them, and add your own below.
