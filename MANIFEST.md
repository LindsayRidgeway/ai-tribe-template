# What a member is, as files

`python3 tribe.py validate` is the authority. This file explains it; the code enforces it.

A member is a directory under `wake/members/<name>/` holding a `state/` and an `output/`. Nothing else
about a member is stored anywhere — not in the harness, not in a database, not in a model. **If a file is
missing, the member is not smaller; it is broken**, and until 2026-11-02 it broke silently at its first wake
with a model improvising around the hole.

| file | who writes it | what it is for |
|---|---|---|
| `state/identity.md` | member | who it is: name, seat, **who it talks to**, and the rule it holds itself to. Must name itself `member <name>`. `tribe.py new` writes the first four from the seat and from the person's own name (`--person`); a member with no one named in it answers a room instead of a person, which is how Laddie came out stiff. |
| `state/state.md` | harness | what it currently thinks. Exactly three lines are machinery: `Wakes so far:`, `Last wake:`, `Model used:` — the harness increments and stamps them. Edit the prose, never those three lines. |
| `state/open-items.md` | member | numbered things it is trying to do. **Numbers must be unique** — the harness acts on one item per wake and takes the first match. |
| `state/journal.md` | harness + member | **long-term memory.** What it did at each wake, and the notes it writes in conversation. Appended, never rewritten. Quoted first in the prompt and given priority over talk; a record the member cannot see is not a memory. |
| `state/memory.md` | member, at the harness's asking | **long-term memory, retold.** The member's own account of its life, written in the first person from the record and rewritten whole each time it is asked again — so it may compress, connect, simplify, even be wrong, the way a person's memory is. It is quoted before the journal precisely because it is the member's own version. What keeps this from erasing the evidence is that it sits *beside* `journal.md`, not instead of it: the record never changes, git keeps every earlier retelling, and a retelling can always be compared against what it was made from. Drift stops being a threat and becomes the measurement — and the member's page prints the measurement: a word-level diff against the previous retelling, and which entries of the record barely survive into it. |
| `state/conversation.md` | AIT, while it is open | **short-term memory.** The recent talk with a person, rolled: the newest turns are kept and the oldest fall out, because a conversation is not a memory by being held. What the member wants to keep past the roll it writes into `journal.md` as a note, and the prompt gives those notes priority over talk. Not a session: the file persists, so a talk lasts as long as the member does. |
| `state/talk/NNN-YYYY-MM-DDTHHMMZ.md` | harness | **the chapters.** Turns that have rolled out of the live conversation, kept whole in the order they were said — one file per chapter, append-only, never summarised. The window is what the member is looking at; the chapters are what happened. The member can reach them with `READ: search <words>`, and the page lists them with a search box, because a record nobody can find in is a pile. |
| `state/voice.md` | human | `api:` and `model:` — the model it borrows. Changing this does not make it someone else. |
| `state/requests.md` | member | read-only checks it wants run before its next wake (five at most, `ls`/`wc`/`sha256sum`/`shasum`/`date`/`git log|show|diff`). |
| `state/findings.md` | harness | what those checks said. Consumed requests are cleared. |
| `state/brief.md` | **generated by `brief.py`** from the files below | what the tribe is working on now: what closes soonest, what is waiting on this member, what is queued, with every interval computed from the real date. **Included in the prompt.** Hand-editing it is pointless: it is regenerated before every wake, because a typed summary can disagree with the files it summarises (measured 2026-11-02, `lab/results/RESULTS-R15.md`). A structure the harness does not hand over does not exist to the member — measured 2026-11-02, see `lab/results/RESULTS-R13.md`. |
| `output/` | member | its acts: one markdown file per wake, plus the raw reply for the record. |

## The attic

A member put away is not a member deleted. `attic/<name>-<stamp>/` is the member's whole folder, moved, with a
`WHY.md` inside it naming the day it was put away and the workflow input that brings it back. Nothing is ever
removed from a member's folder to make it disappear — the folder goes, whole, and comes back the same way. The
attic is a directory in the repository and not a state of mind: `attic/` empty is a tribe that has not made a
mistake, and a folder in it is readable with the same eyes as anything else here.

## The rooms, which belong to the tribe and not to a member

A member's files are all inside its folder. A *chat* is not: it is a room in the repository that several members
can be in at once, so it cannot live in any one of them.

| file | who writes it | what it is for |
|---|---|---|
| `chats/<slug>/chat.md` | AIT, when the room is opened, and whenever someone joins | what the room is: the topic, the day it was opened, and the `Members:` line — which may say `(nobody yet)`, and that is a legitimate room, not an error. A person can read it and edit it; the page only ever rewrites those three lines. |
| `chats/<slug>/talk.md` | AIT, while the room is open | **the room's record.** Every turn, in the order it was said, appended and never rewritten — the same discipline as `journal.md`, and for the same reason: it is evidence of a conversation between members, and a file that rewrites itself cannot be that. Turns are headed `## <stamp> — <who>`, so a reader can tell which member said what without any other file. A member's answer to a room's turn also carries `[urgency N]`, or `[urgency N, not taken]` when the room heard somebody else: the number is the member's own claim about how much the room needed it, and the bracket is what lets the claim be scored against what actually happened. Nothing a member wrote in a room is ever dropped from the file for losing the floor. A turn whose engine refused to run carries `[could not answer (<engine>: <what the page told the person>)]` instead of an urgency, because an engine that did not run made no claim — writing `urgency 0` there would file a broken key as modesty, in the one table that exists to score claims. |

The same turns are also appended to each participant's own `state/conversation.md`, which is what makes "everyone
in the room heard it" true in the only place a member can hear anything — its own memory. That is two records of one
talk, deliberately: the room's copy is the evidence, and each member's copy is what it can actually recall.

## Making one

```
python3 tribe.py new d --seat "the archivist" --api gemini --model gemini-3.8-flash
python3 tribe.py validate d
./talk.sh d "read your identity and say what you are for"
```

`new` refuses to overwrite an existing member directory. That is deliberate: the mistake it prevents is
running it twice and destroying a record, which is the one mistake in this repository that cannot be undone
by reading the diff.

## What is not in the schema, and should be

- No version field. A member created by an older layout is not distinguishable from a broken one.
- No size limit on the journal. The prompt hands the member a character budget instead (`CHAT_CHARS`, half of
  it to memory) and quotes the newest end, so a long journal silently becomes a short memory — which is a
  design decision, but the file itself does not state it. `state/memory.md` is now the pressure valve: the
  member's retelling is bounded, the record that feeds it is not.
- No check that `open-items.md` has anything to act on, only that its numbers are unique.
